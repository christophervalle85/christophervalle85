# Christopher Valle

I’m a software engineer working across full-stack development, systems programming, and cybersecurity. I build security tools that show the evidence behind a finding or a policy decision.

[Portfolio](https://christopher-valle-portfolio.vercel.app)

## Security projects

- [IRSnapshot](https://github.com/christophervalle85/IRSnapshot) collects Windows endpoint snapshots and generates standalone triage reports that trace findings back to the original evidence.
- [ContainerGuard](https://github.com/christophervalle85/ContainerGuard) scans public Docker Hub `linux/amd64` images with Trivy, saves downloadable CycloneDX SBOMs, and checks scan results against versioned policies.
- [MCP Approval Gateway](https://github.com/christophervalle85/mcp-approval-gateway) is a local prototype that checks tool calls against policy, requests human approval for supported actions, and records tamper-evident audit events.
- [Mini SOC Lab](https://github.com/christophervalle85/soc-lab) documents Windows and Linux monitoring with Wazuh, Sysmon telemetry, and investigations from controlled simulations.

## Apps and systems

- [iPhone workout planner](https://github.com/christophervalle85/fitness-app) lets you build weekly routines, log strength and cardio sessions offline, and see what’s left on your plan.
- [PacketSniffer](https://github.com/christophervalle85/PacketSniffer) is a C++ command-line tool that captures live traffic with libpcap and decodes IPv4 and TCP headers.
